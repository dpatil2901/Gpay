G-PAY— ANDROID INSTALLATION

This is an installable web app (PWA), not an APK and not a banking app.
It displays an illustrative sample balance only. It is not connected to Axis Bank,
Google Pay, UPI, or any financial account. The passcode is a local demo gate,
not a UPI PIN. Never enter your real UPI PIN into this sample.

INSTALL:
1. Put the contents of this folder on an HTTPS static host (for example, a
   private static site you control). PWA installation requires HTTPS or localhost.
2. Open the hosted index.html address in Chrome on your Android phone.
3. Open Chrome's three-dot menu and choose "Install app" or "Add to Home screen".
4. After the first successful load, the app shell is cached and can open offline.

install it as a standalone offline PWA from a file. This package does not contain
